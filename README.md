Web Project Homeland

Este projeto foi desenvolvido como parte do Sprint 5 do curso de desenvolvimento web da TripleTen. O objetivo é criar uma página web responsiva que exibe as cidades natais de alguns funcionários da TripleTen, aplicando conceitos de design adaptativo, estrutura BEM, e boas práticas de CSS e HTML. Os Objetivos do Projeto foram: Praticar o desenvolvimento de layouts responsivos baseados em um design do Figma, garantir uma boa experiência de navegação em diferentes dispositivos e tamanhos de tela (320px, 768px e 1280px). Tive como objetivo também reforçar o uso de Flexbox, valores relativos (% e fr), e media queries. Alem dos anteriormente mencionado tivemos tambem, aplicar a estrutura de pastas e classes conforme a metodologia BEM. Publicar o resultado final no GitHub Pages.

Tecnologias Utilizadas HTML5 CSS3 Flexbox Media Queries (breakpoints: 544px e 1024px)
